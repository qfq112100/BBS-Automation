02 / START HERE

第一次用，先看这里

BBS 就是把常用操作放到一个地方。先把目录选对，再照着步骤点；不需要一开始就研究所有参数。

一个文件打开 BBS，五个页面办日常，三款工具点名字就能开。

这本手册的三个约定

  • “Game”指你要操作的外服游戏安装目录中的 Game 文件夹，不是桌面快捷方式，也不是随便一个游戏目录。
  • “缓存”是业务文件的本地存放位置，不是网页缓存，也不等于整套游戏安装包。
  • 文案可以有气势，功能不能瞎编：速度、系统兼容、第三方效果都以你的真实环境为准。
阅读方式

第一次使用按页码顺序看；已经会用，直接翻最后一页的“黄金操作卡”。本手册以原3.3.9说明为基础，已补充旗舰版和顶部说明书入口；按钮文字以当前 BBS 为准。

03 / QUICK START

从零到顺手，只走这五步

不用一上来就懂目录结构。先把两个位置选对，再做一次你看得懂的操作。

01

打开 BBS

双击 BBS 自动工具，确认来源并等待本地服务就绪。新配置的自动联动可能默认开启；若想先熟悉操作，请先暂停自动调度，再配置目录。不要让另一套程序同时写同一游戏目录。

02

选择正确的 Game

在旗舰版或设置中选择外服 League of Legends 的 Game 文件夹。看到配置路径后再核对一次，别把启动器快捷方式当成目录。

03

确定缓存从哪来

已有旧缓存：到“备份任务”导入已有缓存。没有旧缓存：先确保 Game 里确实有你要保存的业务文件，再做“立即备份”。

04

先手动确认一次

备份是 Game → 缓存；恢复是 缓存 → Game。确认方向、目录和结果，再考虑开启自动联动。

05

按需打开工具

旗舰版右上可点 ABC / Rose / Akari；工具中心还能查看运行状态和应用目录。首次准备需要解压，稍等，不要连续狂点。

第一次最容易踩的坑

不要拿空的 Game 当成“有内容的备份源”。自动在线镜像会反映空Game 里的实际情况，可能清掉缓存内的BBS 负责的文件。手动“立即备份”仅复制，不删除缓存独有项。已有重要缓存，先另存一份再练习。

完成标志

Game 路径正确、缓存路径明确、本地服务已连接、手动操作完成提示可理解。先做到这四件事，再追求“自动”。

04 / WORKSPACE MAP

五页工作台，各管一件大事

看状态、做操作、查结果、改习惯、开工具。分工清晰，才叫真正的“顺手”。

页面它负责什么什么时候用
旗舰版看大厅状态、自动调度、缓存条目、最近同步与存储位置；右上快捷打开三款工具每天打开先看这里
备份任务立即备份、恢复到游戏、导入已有缓存、查看任务进度与取消要亲自搬运业务文件时
运行日志查看最近执行记录、刷新、打开日志目录、查看实际提示“我点了，它到底做了什么？”
设置调整 Game / 缓存位置、自动联动及相关运行偏好，保存设置换目录、改节奏时
工具中心打开 Rose、Akari、ABC；看状态、打开应用目录管理第三方工具入口时

三个藏不住的顺手设计

  • 左下“打开总目录”：直接到当前 BBS 数据总目录，不用在隐藏文件夹里翻来翻去。 顶部的“使用说明书”也能直接打开本页；说明书已放进 BBS EXE，不用另外找文件。
  • 右上主题切换：浅色清爽，深色沉浸；换主题不改变备份方向和业务规则。
  • Ctrl + 1—5：快速切换五个页面。左下提示虽然移除了，快捷键仍保留。
别把状态看反了

“本地服务已连接”是本机通信正常；“大厅在线”是匹配安装路径的大厅进程被检测到，不代表登录成功或网络畅通，更不等于第三方工具效果已经生效。

05 / THE ENGINE

三句话，讲透自动联动

它不是玄学，也不是“看到游戏就随便复制”。记住这张方向图，绝大多数误会就能省掉。

大厅刚启动缓存 → GAME
在线持续运行GAME → 缓存
离线 / 未知自动任务暂停
检测到什么自动做什么白话理解
大厅启动 / 首次观察在线安排缓存 → Game 的直接覆盖把缓存里保存的业务内容放回游戏目录
持续在线按设置周期 Game → 缓存镜像按当前 Game 状态更新本地留存
离线或未知不自动复制、删除、最终补备份或清理 Game没有可靠在线状态，就不擅自动手
速度取向的另一面：不是历史版本保险箱

缓存是镜像目标，不是“每次都留一份”的时间机器。Game 里的BBS 负责的内容为空或删除时，在线镜像可能相应清掉缓存里的BBS 负责的文件。误操作之后，不应指望旧版本一定还在。

只管这些业务项，不承包整个游戏

目录：saves、shards。根文件：bot_5.dll、config.ini、hc.dat、HID.dll、shards.json、user.ini。业务范围以程序实现为准；不是把整个 League of Legends 安装包、所有设置和个人文件都备份起来。

开关也很重要

自动规则以对应自动调度已开启为前提。手动备份、手动恢复是你主动下达的动作，不要把“离线不自动操作”理解为“任何时候都不能手动操作”。

06 / MANUAL CONTROL

备份与恢复，方向比手速重要

一个把现状留下来，一个把留存放回去。名字只有两个字的差别，方向却正好相反。

01

立即备份｜Game → 缓存

先确认 Game 里有你要保存的业务内容；核对缓存目标；点击“立即备份”，确认同名覆盖后等待完成完成提示。手动备份仅复制，不删除缓存里独有的BBS 负责的文件；与自动在线镜像不同。

02

恢复到游戏｜缓存 → Game

先确认缓存中保存的是你想用的内容；核对 Game 目录；点击“恢复到游戏”；读清提示后执行；完成后再检查结果。

03

导入已有缓存｜旧目录 → 当前缓存

到“备份任务”选择已有缓存目录。导入只复制识别的业务项，不删除或搬走原目录；它也不等于导入整套工具或账号资料。

04

取消任务｜停止后续工作

可以请求取消，但直接复制不是事务。已经覆盖的文件不会因为取消就自动回到原状；界面完成提示比“按钮已经按下”更重要。

这段要认真看一次

恢复采用直接覆盖，没有自动回滚；失败或取消可能留下部分、截断的目标文件。手动恢复不会为了等一局结束而自动延迟执行。请在你明确知道影响、并适合操作的时机使用。

最稳的学习姿势

第一次先准备一份独立的安全副本，再练习备份与恢复。不要把磁盘根、资料目录或整套游戏安装目录随便当成镜像目标。

07 / MAKE IT YOURS

设置不是越多越好，合适才叫高级

先把路径定住，再安排自动节奏。你要的是少操心，不是让几个程序同时抢着写文件。

设置重点小白该怎么理解
Game 目录告诉 BBS 要处理哪一套外服游戏的业务文件。换安装位置后要重新核对。
缓存目录告诉 BBS 留存内容放在哪里。可以是你选的普通目录；切换位置不等于自动搬家。
自动调度 / 大厅联动是否让 BBS 根据大厅状态执行约定动作。先熟悉方向，再开启。
同步间隔设置页为 1—1440 分钟；新配置结构默认5分钟，实际以界面保存值为准。只在大厅在线时生效，不是实时同步。
桌面偏好主题可选深色/浅色；关闭窗口可选每次询问/最小化到托盘/退出；开机启动为开启/关闭。
确认与保存主题、间隔及桌面偏好修改后点“保存修改”或 Ctrl+S；目录选择经确认会即时保存，不用把它当成未提交的普通输入框。

给想省心的你，三条实用建议

  • 保持单一写入者：别让旧版 BBS、计划任务、其他同步软件同时写同一对 Game / 缓存目录。
  • 换缓存位置前，先决定旧数据如何处理；程序切路径不会替你悄悄迁移全部旧内容。
  • 看到“未知”先查路径和客户端状态，不要为了把状态变绿而反复点恢复。
自动 ≠ 可以完全不看

在线镜像会忠实反映Game 里的实际情况。重要内容另留独立副本；尤其是第一次启用、换目录和升级后，先确认一次实际方向与目录。

几个好用的快捷键

以下快捷键只在 BBS 窗口获得焦点时使用。Ctrl+B：立即备份，仍需确认；Ctrl+R：切到备份任务并请求恢复，仍需确认；Ctrl+S：设置页保存。F5：日志页刷新日志，其他页刷新状态，服务未启动时重试启动。

08 / THREE TOOLS

三款工具，一个顺手的出发点

不是把所有功能硬塞进一个窗口，而是把“准备、打开、找目录”这三件小事，收拾得明明白白。

工具BBS 帮你做什么打开以后去哪用
Rose 1.4.9首次准备程序与配套 LTK 依赖，点击后启动，提供应用目录入口主要按 Rose 原程序流程，在游戏客户端相关界面使用
League Akari 1.5.1准备完整运行时并打开独立应用；已运行时尝试显示原窗口在 Akari 自己的窗口中操作；面向 Riot 客户端
ABC · 外服账号管理工具准备精简程序、必要依赖和干净基础数据；打开或恢复同一实例在 ABC 自己的账号管理与设置界面配置使用

两种入口，做的是同一件事

  • 省一步：旗舰版右上直接点 ABC、Rose、Akari。
  • 看得更清楚：工具中心点“打开”，并查看应用状态、版本说明和应用目录。
  • 第一次稍等：内置文件需要释放；之后会复用相应目录，不是每次都把你的配置抹掉重来。
  • “打开目录”用于找实际应用文件；未准备时可能暂不可用，先点“打开”即可。
单 EXE 的正确理解

只带一个 BBS EXE 方便分发，不等于运行时不产生文件。工具会释放到本机数据总目录的 components 下；它们以自己的进程和界面运行。

不是“全自动代替原软件”

本版没有独立 LTK Manager 卡片，也不靠大厅状态自动拉起这三款工具。BBS 提供入口，不替第三方软件承诺账号、网络、版本、兼容或效果。

09 / ROSE PLAYBOOK

Rose：入口够简单，版本别乱混

你不需要再四处找那两个依赖文件。但也别把“程序启动成功”当成“每一款皮肤都已经生效”。

01

从 BBS 打开 Rose

在旗舰版右上或工具中心点击 Rose。第一次等待文件准备；若按原软件要求弹出管理员确认，核对程序与来源后再决定。

02

到原软件流程里使用

Rose 通常在游戏客户端相关环境中使用。具体选择、构建、应用等流程，以 Rose 原界面与说明为准；不是在 BBS 里另造一套换肤按钮。

03

需要文件时再开目录

从工具中心“打开目录”进入当前实际 Rose 目录。不要只凭文件夹名手动挑一个旧版本来运行。

04

有错误先留证据

记录时间、游戏版本、Rose 提示及日志关键内容。版本错误、权限问题和效果未生效不能都归结为“文件少了”。

LTK 配对，已经随包准备

当前使用原始签名的 LTK 1.29.0 host / DLL 配对，由 BBS 随 Rose 一起准备，不需要用户再安装独立 Manager 或手工搬两个文件。不要把不同版本 DLL 混搭，不要按旧教程随意换回其他配对。

这句实话，比漂亮口号重要

挂钩、DLL 加载或资源重定向的日志，不等于用户已确认所有视觉效果。游戏更新和第三方兼容性都可能变化；不保证账号安全、游戏条款许可或绕过反作弊。不要为排障关闭安全组件、改系统时间或伪造宿主。

“正在运行”不是重复启动的邀请

Rose 已经运行时，不必反复打开。工具中心显示运行状态，仅说明进程被识别，不代表每个第三方功能都完成验收。

10 / AKARI + ABC

独立窗口，各有各的主场

入口可以统一，账号、运行条件和原软件规则不能凭空统一。各归各位，才不容易迷路。

League Akari｜打开之后，在自己的窗口用

  • 从 BBS 点击 Akari，首次等待完整运行时准备；已运行时尝试显示原窗口。
  • Akari 面向 Riot 客户端，不应把它当成腾讯国服通用工具。
  • 登录、网络、权限和功能配置，以 Akari 自己的界面及原说明为准。BBS 不是替代服务商，也不接管你的所有账号操作。

ABC｜第一次是干净工作台，不是旧账号搬家

01

打开 ABC

点击“ABC · 外服账号管理工具”或旗舰版 ABC 入口。按要求确认管理员权限，等待程序显示。

02

填写自己的必要配置

账号、密钥、路径等按原软件要求自行配置。内置基础数据不夹带原电脑个人账号；需要什么由你主动填写。

03

保存后，下次继续用

本机对应工具文件夹里的已保存配置会复用。再次点击优先恢复同一实例，不用靠多开来找窗口。

没有把约 4GB 缓存偷偷塞进 EXE

ABC 内置的是精简程序与必要依赖，不包括原始汉化缓存、个人账号、密钥或历史日志。需要的资源由 ABC 按自身功能管理；不保证第一次离线就能完成汉化相关操作。

账号资料，按私密文件保管

工具文件夹可能保存敏感登录资料。不要把整份运行数据发群里；也不要为了“试试看”执行载荷中的插件安装、卸载或结束游戏批处理。

11 / KEEP YOUR WORLD

总目录守好，换机才有底气

配置不是跟着桌面图标飞来飞去的。EXE 负责把程序带过去，数据备份负责把你的习惯带过去。

东西在哪里 / 怎么找
BBS 配置与日志默认在当前用户 LocalAppData 下的 LOLBackupV3；左下“打开总目录”直接进入实际根目录。
释放的工具与其组件数据总目录的 components 子目录；当前使用哪个路径，以工具中心“应用目录”为准。
游戏业务缓存在你设置的缓存目录；可能在桌面，也可能另选位置，不一定在总目录里。
第三方额外数据若原软件自行另建应用数据目录，也需按其设置确认；不要一概猜测全部只在一个位置。
01

备份前先退出

退出 BBS 及内置工具，避免正在占用的数据库只复制到一半。

02

复制两类重要东西

完整保存总目录；另存你实际设置的游戏缓存目录。重要资料再留一份独立副本。

03

换机后重新核对

EXE 可在新电脑准备工具文件，但旧电脑配置不会自动跟着 EXE 迁移。恢复你自己的数据后，重新检查新机 Game / 缓存路径与运行条件。

04

升级时先留旧目录

新版工具可能建立新版本子目录。旧数据保留不等于新版自动迁移；确认新版确实用上原配置后，再考虑清理旧目录。

给别人修改：发源码包，不发你的生活

源码归档是给开发者的；运行总目录可能含账号与密钥，是给你自己备份的。两者不是一回事。不要把“完整交接”误解成“把私人运行数据也打包送走”。

12 / RESCUE DESK

有问题，先按这张小抄排

别一出错就重装、删目录、关安全软件。先分清是哪一层，排障速度自然更像高手。

现象先做什么
本地服务未连接 / 正在退出等待状态更新完，查看完成提示与日志；不要在关闭过程中强点任务。
大厅显示离线或未知核对外服客户端是否运行、Game 路径是否正确；未知不是可靠在线，不要用恢复按钮“刷绿”。
按钮变灰查看是否正在执行任务、目录是否有效、服务是否就绪；禁用状态不等于程序坏了。
备份后缓存为空先看源 Game 的BBS 负责的业务文件是否为空；镜像不是历史版本保存箱。
恢复后与预期不同立即核对方向和实际目录；直接覆盖没有自动回滚，不要连续反复尝试。
首次打开工具较慢正在准备运行文件时等待，不要反复多开；若失败看具体错误，不要盲删配置。
工具提示权限或被系统拦截核对来源、签名及原软件要求；使用可信渠道的运行条件，不要一键关闭防护。
ABC 已运行但窗口没到最前看任务栏并点击原窗口；Windows 可能限制后台自动跳到最前面，不代表需要再开一个进程。
找不到配置 / 不知道哪个目录在用点左下“打开总目录”；工具中心看“应用目录”；缓存另看设置中的实际路径。
求助这样说，效率翻一档

13 / HONEST ANSWERS

问题可以问直白，答案必须说实话

排面可以拉满，边界不能靠猜。把这几件事分清，后面就少走很多弯路。

一个 EXE，为什么还会释放文件？

单 EXE 是分发方式。第三方程序需要自己的运行文件，点击工具后释放到本机目录，属于正常设计。

别的电脑能用吗？

设计上可以复制 BBS EXE 后准备工具文件；仍需满足相应 Windows 位数、权限及 .NET / VC++ 等条件，不能承诺所有电脑无条件可用。

换电脑会带上我的 ABC 账号吗？

不会只靠 EXE 自动带过去。新机初始基础数据是干净的；迁移你自己的数据要单独备份和恢复。

工具配置每次会被覆盖吗？

当前已准备的 ABC 可变配置不会因为重复打开被重置。未来换工具版本，是否迁移旧配置需另行确认。

离线是不是会做最后一次备份？

当前规则不是。离线 / 未知不自动做最终备份或清理 Game；需要的手动动作由你明确执行。

是不是整套游戏都给我备好了？

不是。只处理约定的业务目录和文件，不是完整游戏、所有存档或所有账号的全量备份。

现在有内置网盘备份吗？

当前版本没有内置网盘登录和自动上传。网盘只是讨论过的设想，不是现成功能。

运行成功就说明换肤一定成功吗？

不说明。启动、挂钩、加载和实际视觉效果是不同层级；第三方兼容与游戏版本仍需具体确认。

最值得记住的一句话

把 BBS 当成入口与文件工作台，不把它当成全能保险箱、官方游戏承诺或账号安全担保。
