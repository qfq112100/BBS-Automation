## Windows快速编译

准备PowerShell和与[锁定信息](<toolchain.lock.json>)相符的LLVM-MinGW（发行使用20261020 / Clang23.1.4 / UCRT）。从源码根目录执行，示例工具链路径请替换为你自己的实际位置：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -ToolchainBin 'C:\Tools\llvm-mingw\bin' -BuildDir .\build -Mode App -Architecture x86
```

默认输出build/LOLBackup.exe。脚本直接调用匹配的编译器、windres和objdump，不自动安装工具链或改变系统环境。CMake是可选构建方式，不是这个PowerShell入口的必需条件。

需要编译并运行原生测试时：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -ToolchainBin 'C:\Tools\llvm-mingw\bin' -BuildDir .\build -Mode All -Architecture x86
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_tests.ps1 -BuildDir .\build -Architecture x86 -NoBuild -TimeoutSeconds 120
```

## 修改前必须知道的业务约定

业务只处理saves、shards以及bot_5.dll、config.ini、hc.dat、HID.dll、shards.json、user.ini，不是整个游戏安装目录。

1. 大厅启动/首次观察在线：缓存直接覆盖Game中托管业务文件，不等待对局退出。
2. 在线时：按用户设置周期从Game镜像到缓存；源为空时也反映到托管缓存，不把旧缓存误当真值。
3. 离线或未知：不自动复制、删除、做最终备份或清理Game。手动动作仍按现有业务执行。
4. 工具准备/启动独立于DIRECT同步队列，不得因为新增工具而改变上述逻辑。
5. 当前ABC可变数据仅限清单列出的五个配置/数据库路径。初次种子仍核对SHA；后续不覆盖用户修改。共享占用只用受约束的元数据检查；不可变程序仍按既有完整性规则处理。
6. 已运行ABC按确切映像路径/PID恢复原窗口，不重复启动；系统不允许前台激活时请求任务栏注意，不绕过Windows焦点规则。
