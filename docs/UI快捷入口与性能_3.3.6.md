# 3.3.6：非卡片式概览快捷启动与局部重绘优化

## 界面

概览右上添加固定的Rose/Akari图标文字快捷按钮（112×32逻辑像素，间隔8），默认与标题栏融为一体，悬停/按下时轻量强调，键盘焦点有描边；没有新增容器卡片。浅深色、96/120/144 DPI、缩放和滚动均测试。只在概览显示，不随正文滚动，不覆盖标题/副标题；原工具中心入口保留。

原生ID112/113复用原SendTool600/610打开路径：首次自动准备、忙碌时禁用、已有实例按既有规则处理；不因未准备或正在运行就长期灰掉打开按钮。隔离预览故意禁用真实启动，强制命令也不会释放或运行第三方程序。

[浅色预览](<verification-ui-3.3.6/overview-light.png>) · [深色预览](<verification-ui-3.3.6/overview-dark.png>)。截图是隔离预览，缓存/调度数据不是用户实际配置，快捷按钮也按预览安全规则呈禁用状态。

## 实际优化

1. 文本绘制先判断是否落入脏区，侧栏Logo不在脏区时不再做高质量缩放/绘制。原有持续复用的backbuffer和Hero缓存保留，不冒称这两项是本次新增。
2. 日志滚轮和拖动仅使完整滚动轨道/旧新滑块覆盖范围失效，保留原生编辑框自行刷新；一般页面布局仍重绘固定标题与页脚，未缩成会留下旧像素的正文区域。
3. 目录可用性从绘制/布局循环中移出，以路径变化或每2秒有界刷新UI缓存；点击打开目录时仍即时校验，核心文件校验、启动和备份业务未改。

## 同参数A/B

同一冻结测试脚本SHA256 D6123C64FB1F1394268DBE93C1092DADD5C54CECD9277A7485BD99764D5E6835，同一983×727逻辑窗口/DPI96，每个二进制3次新进程运行，每项20次预热与120次计时。数值为3轮“轮均值”的中位数，P95也取3轮P95的中位数，不是拼接全部样本。

| 同步绘制场景 | 原平均耗时 | 优化后平均耗时 | 下降 | 原P95 → 新P95 |

| 页脚局部 | 2.450ms | 0.327ms | 86.7% | 2.601 → 0.266ms |

日志项是一对滚轮输入及编辑框/父窗口同步刷新，不是单个滚轮事件；整窗的小差异可能在环境噪声内，不能称为显著提升。数据不是系统性能、GPU/FPS、桌面合成呈现延迟或换肤正确率。全部24项场景GDI/USER句柄增量0，6个测试进程正常退出；循环前后日志第一行0→0，工作负载一致。源码性能计数仅在smoke启用，普通运行不累计；计数窗口包含定时刷新，不能把采样差值说成严格每次输入次数。
