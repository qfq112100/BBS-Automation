# BBS 3.3.1.0 UI 修复验收

## 修复内容

1. 滚动原生按钮（包括工具中心复选框和强停按钮）使用最终物理像素坐标与内容视口相交；先提交位置，再提交对应窗口区域。
2. 所有滚动按钮的原始绘制目标DC增加视口裁剪，涵盖离屏缓冲绘制和分配失败回退，避免瞬态位置/区域不一致时画入固定页眉或底栏。
3. 滚动完成后补刷右侧内容、固定页眉及底栏，修复原有视口外残影；不移动/隐藏固定导航、标题栏。
4. 托盘菜单持有离屏缓冲，将背景、文字、勾选与高亮画成完整帧后一次提交；悬停只使旧、新高亮行失效，分隔符和禁用项不高亮，离开时清除高亮。
5. 日志/多行查看器累计小幅滚轮输入，父窗口只转发一次；四次30单位输入与一次120单位输入效果一致。
6. 工具目录尚未准备时不再直接进入Shell并显示Shell2；改为明确提示先准备/检查。“无错误”改为“启动管理未报错，内部功能或注入结果请在工具内查看”。补齐Ctrl+1–5提示。

主要代码：[原生窗口](<../src/app/main.cpp>)、[物理裁剪与滚轮计算](<../src/app/ui_geometry.h>)。

## 实际复现与验证

- 旧版在同一隔离环境中复现滚动残影：轮滚步骤的固定底栏有12896、16643、10608个像素在强制重绘后改变；旧托盘悬停也出现高亮行之外的像素变化。
- 新版100%、125%、150%预览缩放各 **790项检查通过，0失败**；浅色主题100%也执行相同检查。预览缩放不改变用户系统显示设置，不等同于覆盖全部真实多屏DPI切换场景。
- 覆盖全部5页面、快滚及反向、不同窗口尺寸、14个实际工具控件、真实窗口区域、固定页眉/底栏、托盘各行悬停、文字非空、键盘导航、Esc关闭及点外关闭。
- 检查使用真实窗口GetWindowRgn与屏幕CopyFromScreen像素；没有用程序自带导出、WM_PRINT或PrintWindow代替屏幕。菜单首次显示先同步绘制及DWM合成，避免把首帧前的桌面误当成菜单。
- 日志父窗口和编辑框两条路由均验证整格/细粒度滚轮等效。
- **13个回归测试程序全部通过**；新增几何与滚轮单元测试 **20938项通过**。
- 同步引擎、服务、工具管理器及内置3个Cabinet包、组件清单与修复前SHA-256完全相同。没有修改大厅/缓存规则或Rose/LTK二进制。

## 边界

采样帧一致不等于证明任意显示器、驱动和负载下绝无帧间闪烁；文字边缘检测也不是OCR。低GDI资源分配失败时菜单保留直绘回退，不承诺该退化路径的原子帧。测试只操作独立烟测PID，未重试真实游戏注入、关闭安全功能或强停游戏/第三方工具。

**本次仅修复UI。Rose/LTK的实际游戏附加兼容问题没有修复，不以“进程运行中”声称换肤成功。**

发行版本3.3.1.0；准确大小、SHA-256见[发行清单](<verification-ui/release-manifest.json>)。另外修复了浅色隔离预览进入设置后误判“未保存修改”的问题，未改变真实用户配置保存逻辑。
