LOLBackup 3.3 DIRECT · 候选 3.3.0.0 · 原生 Win32 C++17 · 同步四层 + 独立工具 worker：完整应用按需释放

DIRECT 数据流

  • • 恢复：物理缓存白名单只枚举一次，每个文件 CopyFileExW 覆盖 Game，同内容也复制。
  • • 不预扫 Game、不哈希跳过、不暂存原子替换、不最终复验；不删 Game 额外项。
  • • 定时镜像：以物理 Game 为真值，覆盖并删除受管差集；仅确认在线时完整空 Game 才清空全部受管缓存。
  • • 手动备份仅复制不额外删除；导入不移动/删除源。

大厅与定时器

  • • 默认独立采样 500ms，首次观测在线立即安排恢复，不等第二次确认或对局退出。
  • • 持续在线按用户间隔镜像：默认 5 分钟，可设 1–1440 分钟。
  • • 离线/未知即使 Game 随后变空，也无自动复制/删除/最终补派任务；不追加对局结束备份或自动清理 Game。
  • • 空缓存无文件可恢复；失败恢复不冻结未来镜像。
  • • 恢复/逐文件/逐块取消只读原子状态；自动 fullMirror 的 mirror/verified 删除前仅额外一次新鲜 ProbeLobby，确认仍在线才删除，不做内容复验。

范围、风险与验证

  • • 保留配置路径、根不重叠、基本重解析点与白名单检查；不改 ACL 或系统安全策略。
  • • 取消用 PROGRESS_STOP 留下当前部分目标，不用 PROGRESS_CANCEL 删除式清理；直接覆盖可截断旧目标，错误按 Windows 实际结果报告，无回滚。
  • • 无目录所有权/身份批准、持久还原保护、墓碑、历史恢复点或快照；旧元数据保留并忽略。
  • • Windows 权限/占用/磁盘错误如实报告，部分完成不当作成功。
  • • 配置 CAS / 配置原子保存保留，不等于业务原子复制。
  • • 原有隔离目标 + 工具管理测试；不提前宣称全部通过，性能/计数以实测为准。

工具运行条件、许可与验证边界
