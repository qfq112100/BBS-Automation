## 使用边界

- BBS界面是原生Win32/静态C++，但可选工具有独立运行要求。它们要求x64 Windows；Akari面向Riot客户端，不支持腾讯国服。
- Rose/Pengu可能需要.NET Framework4.7.2或更新；Akari更新器可能需要Microsoft VC++ x64运行库。本机检测到.NET4.8及所需VC++基础DLL，不构成所有电脑的保证。
- 默认不跟随大厅，不自动注入。准备只解压/校验，之后由用户明确启动。
- 受管组件为固定版本。检查发现现有目录不一致时会保留并报错，不盲目删除；“检查”不是自动覆盖修复。第三方自更新或游戏更新导致不匹配时，应退出工具、按官方说明处理或采用新的BBS集成包。
- 原同步规则不变：只有在线允许Game空源清缓存；离线/未知不复制、不删除、不补最后一次同步。
- 旧BBS已正常退出并替换，新版未在真实配置下自动启动。既有设置与业务缓存保留；打开桌面新版后进入工具中心使用。
