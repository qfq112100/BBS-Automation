# 工具中心使用说明（BBS 3.3.5 本机签名配对对照候选）

## 只有两个打开入口

- **Rose 1.4.9完整官方应用**：点“打开”自动准备并启动，必要时按其原始要求显示管理员确认。Rose通常在游戏客户端中使用；已运行时不会再启动一个副本。
- **League Akari 1.5.1完整官方应用**：点“打开”自动准备并启动。已在运行时尝试显示其窗口，或交由官方程序自身的单实例机制处理。Akari仅面向Riot客户端，官方不支持腾讯服务器。
- “打开目录”用于查看实际受管目录；未准备时目录按钮可能不可用，直接点“打开”即可，不需要先点准备/检查。

没有独立LTK卡片、LTK Manager安装器、单独准备按钮或强停/跟随工作流。旧工具偏好文件保留，但本版工具只在用户明确打开时启动。两个应用以自己的进程和界面运行，不是伪装成BBS内部原生换肤功能。

## 两个补丁随Rose放置

完整Rose运行目录中直接并排包含：

```text
_internal/injection/tools/ltk_patcher_host.exe
_internal/injection/tools/ltk_patcher_dll.dll
```

不是host/dll两个子目录，也不需要用户另外搬文件。本机对照候选采用未修改、保留双方官方签名的1.29.0配对；1.30.x的新宿主认证在实际日志中拒绝了Rose。详细来源、限制和验证见[全面检查与对照记录](<全面检查与签名对照_3.3.5.md>)。

Rose使用新的组件版本目录，保留旧目录及其用户生成文件。已有Akari仅在原始清单与收据精确吻合时复用，不覆盖用户配置或重写旧标记。

## 单EXE与运行条件

单EXE是分发形态，不等于运行时没有文件。点击打开时自动释放完整运行目录；Rose的Python/Pengu资源和Akari的Electron/Chromium/Node文件都随包保留。BBS本身仍是原生Win32 C++。第三方工具为x64，可能依赖其官方说明中的系统运行条件，例如Rose/Pengu的.NET Framework4.7.2、Akari相关组件的VC++x64运行库。不要从第三方电脑复制系统DLL，不要求关闭安全防护。

当前是个人本机验证候选；签名host的公开再分发须满足上游许可，不能把本候选当作已获许可的公共发行包。

## 备份规则不变

大厅首次确认在线：缓存直接覆盖Game；持续在线：Game按间隔镜像缓存，合法空源可清空受管缓存。离线或未知不自动复制、删除、最后补备份或清理Game。工具启动失败不进入同步工作队列、不改变这些规则。

启动成功、后台就绪或DLL附加都不代表皮肤生效；需要新游戏会话的覆盖验证/资源重定向日志与实际效果确认。
